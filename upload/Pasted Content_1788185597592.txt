# PART 3 — CREATE A FEATURE AUDIT MATRIX

| ------- | --------- | ------------ | -------------- | --------- | --------- | ----- | ---------- | ------- | ------ |

Every feature must receive one of:

### COMPLETE

Real functionality exists.

### PARTIAL

Some functionality exists.

### MOCK

Visual representation/demo only.

### HARDCODED

Content is embedded in frontend code.

### MISSING

No implementation.

### BROKEN

Implementation exists but does not function correctly.

Do not mark a feature complete simply because its page renders.
