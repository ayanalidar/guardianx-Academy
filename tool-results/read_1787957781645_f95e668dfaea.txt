     1→     1→# GuardianX — Cyber Security LMS Platform
     2→     2→
     3→     3→## Project Overview
     4→     4→GuardianX is a comprehensive Learning Management System (LMS) for cyber security certification courses (CEH, CCNA, CCNP, RHCSA, WAPT, CISSP, CYBERARK-IAM & PAM, etc.). It includes:
     5→     5→- Full LMS (course catalog, lessons, PDF study material, on-the-go notes, progress tracking, quizzes, certificates)
     6→     6→- Live sessions with screen sharing + two-way voice (instructor <-> students) via WebRTC + Socket.io signaling
     7→     7→- Cyber security practice labs (open-source style challenges)
     8→     8→
     9→     9→## Tech Stack
    10→    10→- Next.js 16 (App Router) + TypeScript, single `/` route SPA
    11→    11→- Tailwind CSS 4 + shadcn/ui (New York), Lucide icons
    12→    12→- Prisma (SQLite), NextAuth v4 (credentials), Zustand + TanStack Query
    13→    13→- Socket.io mini-service for WebRTC signaling (port 3003)
    14→    14→- Theme: cyber-security dark-first with emerald/green accents
    15→    15→
    16→    16→## Architecture
    17→    17→- `src/app/page.tsx` — single SPA entry, view switching via Zustand store
    18→    18→- `src/views/*` — self-contained view components
    19→    19→- `src/app/api/*` — REST API routes (courses, lessons, enrollments, progress, notes, quizzes, labs, live-sessions)
    20→    20→- `mini-services/live-signaling/index.ts` — socket.io WebRTC signaling server (port 3003)
